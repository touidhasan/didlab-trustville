# Module guides

Each module gets its own guide here as it ships. Every guide follows the same shape:

1. **The problem** — the everyday trust problem in Trustville.
2. **Why a blockchain** — and when a normal database would be the better choice.
3. **Design** — contracts, standards, on-chain vs off-chain data.
4. **Try it** — steps on dapp.didlab.org and what to look for on explorer.didlab.org.
5. **Extend it** — three suggested extensions for a group project.
6. **Security checklist** — what to check before deploying your own version.
